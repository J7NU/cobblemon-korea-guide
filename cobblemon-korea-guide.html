🌏 COBBLEVERSE란?

COBBLEVERSE는 Cobblemon 기반 모드팩으로, 포켓몬 본가 게임처럼 지방(지역) 진행 시스템을 얹은 팩이다. 체육관 리더 → 사천왕 → 챔피언을 꺾으며 관동부터 순서대로 지방을 해금한다.

  • 이 가이드 기준 버전: COBBLEVERSE 1.7.40 (2026-07-11) · MC 1.21.1 Fabric
  • 체육관 총 48개 — 시작 시엔 관동(Kanto) 8개만 발견 가능, 이후 지방별로 순차 해금
  • 전용 구조물(전설 포켓몬 구조물 포함)은 현재 진행 중인 지방의 트레이너 시리즈에 묶여 있음 — 관동 진행 중엔 관동 구조물만 생성
  • 각 챔피언이 주는 책에 다음 지방 진행 방법이 적혀 있음

구버전(코블몬 베이스 모드 1.7) 가이드는 여기에 보관되어 있다. 진화 조건·상성표·아이템 사전 등 베이스 모드 공통 정보는 그쪽 참조.

⚡ 명령어로 전 지역·구조물 즉시 해금

기본적으로 전설 구조물은 각 지방 챔피언을 꺾어야 열리지만, 명령어로 바로 해금할 수도 있다.

사전 조건

  • 치트(명령어) 활성화 필요 (싱글플레이 또는 서버)
  • 서버는 config 폴더가 런처 구성과 일치해야 하고, 데이터팩이 정상 로드되어야 함

실행 방법

  1. 지방별로 아래 명령어 실행: /function setup:지방이름 (예: /function setup:johto)
  2. 필수 순서: Johto → Hoenn → Sinnoh
  3. 명령어 사이에 몇 초씩 대기
  4. 월드/서버를 한 번 껐다 켜기 → 해금된 구조물 전부 생성 가능

원하는 지방만 골라 해금해도 되고 전부 해금해도 된다.

🏛️ 구조물 개요

COBBLEVERSE 전용 구조물은 진행 중인 지방의 트레이너 시리즈에 묶여 생성된다 — 관동 진행 중엔 관동 구조물만 나온다. 좌표 찾기는 아래 방법 사용:

  • 포켓 레이더 (Poké Radar): 로케이터 칩(Locator Chip)으로 제작 → 지도 제작 테이블에 넣으면 전설 구조물 지도 생성 (자세한 방법은 전설·환상 탭)
  • /locate 명령어: 치트 허용 시 /locate structure cobbleverse:구조물이름

🗺️ 체육관 찾는 법

COBBLEVERSE에는 체육관이 총 48개 있다. 시작 시엔 관동 8개만 발견 가능하고 지방 진행에 따라 순차 해금된다.

공통

  • 체육관 지붕 색 = 리더 타입 — 멀리서도 타입 구분 가능
  • 새 게임 시작 시 첫 체육관 지도 자동 지급
  • 지방별 지도 제작 테이블(Cartography Table)을 무직 주민 옆에 놓으면 그 주민이 맵 가이드(Map Guide)로 전직 → 아이템 교환으로 체육관 지도 구입
  • 빈 지도 + 리더의 시그니처 아이템 조합으로도 지도 생성
  • 치트 허용 시: /locate structure cobbleverse:체육관리더이름

지방별 주의점

  • 관동 사천왕 타워는 디 엔드에 있음 — 전용 End Cartography Table 필요
  • 성도 그린 격파 후 월드/서버 재시작 필수 (체육관 정상 스폰) · 성도 지도상인은 관동 완료 전까지 기본 교환만 제공
  • 호연 목호의 책 읽기 + 재시작 · 월드가 넓어 맵 가이드가 반경 1만 블록 내 탐색에 실패할 수 있음 → 지도 제작 테이블 휴대 권장 · 리그 건물은 생성에 72시간+ 소요
  • 신오 재시작 후 Sinnoh Cartography Table 제작 → 무직 주민 옆 설치 · 신오리그 건물 곳곳에 숨겨진 비밀

시그니처 아이템은 트레이너 스포너(Trainer Spawner)에 넣으면 해당 리더를 소환하는 용도로도 쓴다. 각 지방 표의 "소환 아이템" 열 참조.
⚠️ 리더별 에이스 포켓몬·레벨·보상 목록은 공식 위키 미기재 — 공개되면 갱신 예정.

💰 화폐 시스템

화폐버는 법비고
포켓달러 (PokéDollars)야생 포켓몬·트레이너·체육관 리더 격파강한 트레이너일수록 보상 큼
렐릭 코인 (Relic Coin)—쓰지 말고 모으기 — 100개로 타부자고(Gholdengo) 획득

🏪 상인(CobbleMerchant) 3단계 — 효율 비교

상인접근법품목가격
기본 상인진열장(Display Case)을 무직 주민 옆에 설치 — 언제든 가능몬스터볼·몹 드롭·회복약 등 폭넓음가장 비쌈 — 급할 때만
포켓마트 상인 (Poké Mart)커스텀 마을의 파란 지붕 건물기본 상인보다 적음기본 상인보다 약간 저렴
백화점 상인 (Department Store)큰 마을의 쇼핑센터 — 층별 탐색기술머신(TM)·이상한사탕 등 거의 전부최저가 — 최고 효율

원문에 품목별 구체 가격표는 없음 (공식 위키 미기재) — 상대 비교만 제공된다.

🏦 아이템 판매 (Bank)

아무 상인에게나 "Bank" 버튼을 눌러 아이템을 팔아 포켓달러를 벌 수 있다.

  • 판매 가능 예시: 에메랄드, 렐릭 코인, 비타민류
  • 렐릭 코인은 타부자고용 100개를 모을 때까지 팔지 않는 게 이득

✨ 특수 폼 입수 방법

공식 튜토리얼에 실린 특수 폼 6종의 입수 절차. 리전폼(알로라·가라르 등) 야생 스폰 위치는 시작하기 탭의 전국 스폰 도감 "폼" 항목 참조.

지우개굴닌자 (Ash-Greninja)
  1. 평원의 지우의 집에서 지우 방 서랍의 지우의 모자(Ash's Cap) 입수
  2. 모자를 메인 핸드에 들고 개굴닌자 우클릭 — 친밀도 255 필요

배틀 중 개굴닌자가 공격 기술로 상대를 기절시키면 유대변화(Battle Bond) 특성으로 지우개굴닌자로 변신, 배틀 종료 후 원상 복귀.

지우의 피카츄 (Ash's Pikachu)
  • 피카츄의 코스메틱 인벤토리에 Rage Candy 지급 → 폼 변경 (능력치는 일반 피카츄와 동일)
  • 피카슈니움Z 소지 시 1000만볼트 사용 가능 · 단 피카니움Z를 들어도 가득찬볼트는 사용 불가
울트라네크로즈마 (Ultra Necrozma)

필요: Z링 + Solarizer(솔가레오용) 또는 Lunarizer(루나아라용) 제작 + 울트라네크로즈마Z

  1. 솔가레오/루나아라를 Solarizer/Lunarizer로 우클릭 ('충전됨' 표시 확인)
  2. 충전된 아이템으로 네크로즈마 우클릭 → 합체
  3. 합체된 포켓몬에게 울트라네크로즈마Z 지급
지가르데 폼 (Zygarde: 10%·50%·퍼펙트폼)

준비: 지가르데 큐브(Zygarde Cube) + 재조립 유닛(Reassembly Unit) 제작 → 지가르데 셀·코어 수집 (입수처는 특수 아이템 탭)

셀/코어를 담은 큐브로 재조립 유닛 우클릭:

셀코어폼특성소요 시간
9110%오라브레이크2분
49150%오라브레이크5분
95550%스웜체인지10분

퍼펙트폼(100%)은 스웜체인지 지가르데가 배틀 중 HP 절반 이하로 떨어지면 발동, 배틀 후 복귀.

메가지가르데 (Zygarde Mega)
  • 필요: 스웜체인지 특성 지가르데 + Zygardite(제작) 소지 + 메가팔찌 착용
  • 배틀 중 퍼펙트폼 변신 후 메가진화 가능
  • 중요: "Nihil Light" 기술은 메가진화 완료 후에만 사용할 것 (공식 가이드 경고)
이터널플라워 플라엣테 (Eternal Floette)
  • Floettite 제작 + 메가팔찌 착용 + 플라엣테를 Lv.50까지 육성
  • Lv.50에 전용기 파멸의빛(Light of Ruin) 습득
  • 배틀이 끝나면 기술이 사라지고 PP 0으로 다시 배워야 함 — 배틀 전 치료 머신 사용 권장
