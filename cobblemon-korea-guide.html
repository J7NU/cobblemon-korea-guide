통신교환 진화 → 링크 케이블

코블몬에서는 통신교환 대신 링크 케이블(Link Cable)을 포켓몬에게 우클릭하면 진화해. 원작에서 지닌 물건이 필요했던 포켓몬은 그 아이템을 지니게 한 상태에서 링크 케이블을 사용해야 해.

링크 케이블 획득: 조합(네더 석영 + 구리주괴 + 엔더진주 계열, 1.6 개편) 또는 마을·요새·이글루·삼림 대저택 등 상자

진화의 돌

진화의 돌은 지하 광석으로 자연 생성되고, 화석 발굴지 전리품이나 낚시로도 얻을 수 있어. 돌을 들고 포켓몬에게 우클릭하면 진화.

지닌 물건 대부분은 해당 타입 포켓몬 드롭 또는 발굴지·구조물 전리품으로 나와. 상세는 위키 아이템 페이지 참고.

화석 얻는 법

  1. 솔(Brush)을 조합한다 (막대 + 깃털 + 구리 — 바닐라 아이템).
  2. 화석 발굴지 구조물에서 수상한 모래(Suspicious Sand) / 수상한 자갈(Suspicious Gravel)을 찾는다. 일반 블록과 미묘하게 텍스처가 달라.
  3. 수상한 블록에 솔을 우클릭 꾹 — 낮은 확률로 화석이 나온다. 발굴지마다 확정 화석 1개가 보장돼 있으니 모든 수상한 블록을 다 털 것.

화석 15종 → 포켓몬 매칭

가라르 화석 4종은 코블몬에서 교배 불가 (메타몽 포함). 개체값이 필요하면 화석을 여러 번 부활시키거나 하이퍼 트레이닝을 써야 해.

부활 머신 (Resurrection Machine)

  1. 화석 분석기(Fossil Analyzer) + 데이터 모니터(Data Monitor) + 복원 탱크(Restoration Tank) 3개 블록을 준비. 데이터 모니터는 발굴지에서 회수(v1.7).
  2. 분석기와 모니터를 나란히 놓고, 그 위에 탱크를 얹는 L자 배치. 맞게 놓이면 전기 소리가 남.
  3. 분석기에 화석을 넣는다 (호퍼로 자동 투입 가능).
  4. 복원 탱크에 유기물 총 64치를 채운다. 씨앗·음식·몹 드롭 다 되지만 앵무조개 껍데기 4개(개당 16)가 가장 효율적.
  5. 조건이 맞으면 배아가 자라기 시작 — 12분 후 완성.
  6. 완성되면: 몬스터볼을 들고 탱크 우클릭 → 바로 내 파티로 / 탱크를 부수면 야생으로 방출(잡아야 함). 색이 다른 개체(이로치)도 나올 수 있음!

지하에 생성되는 던전으로, 바닐라 시련 스포너(Trial Spawner)가 포켓몬을 소환해. 타입 테마별 방이 있고 클리어 보상으로 좋은 전리품(진화 아이템, 사탕 등)이 나와. 지하 탐험 중 발견하면 꼭 털 것.

마을 포켓센터 (1.6+)

마을에 포켓센터 건물이 생성돼 치료 머신을 무료로 쓸 수 있어. 단, 이 치료 머신은 캐면 철주괴 1개만 나오니 가져갈 생각은 금물. 치료 머신은 주민 직업 블록으로도 작동해서 간호사(Nurse) 주민을 만들 수 있어.

스카이 필러 & 머나먼 유적 (1.7)

  • Sky Pillar: 자연 생성되는 높은 탑. 꼭대기 비콘에 네더의 별을 들고 우클릭 → 뮤츠(Lv.70) 소환. 탑 하나당 1회용.
  • Faraway Ruin: 뮤의 스폰 확률이 크게 올라가는 특수 구조물.

바이옴별 포켓몬 스폰

지금 있는 지형을 눌러봐. 그 바이옴에서 잡을 수 있는 대표 포켓몬이 희귀도순으로 나와.

위에서 지형을 하나 선택하면 스폰 목록이 여기 나타나

커뮤니티 스폰 자료(v1.6~1.7) 기준의 대표 목록이야. 서버 버전·데이터팩에 따라 다를 수 있으니, 게임 내에서 잡은 포켓몬의 도감을 열면 실제 발견 위치가 정확히 나와.

포켓몬 라이딩 1.7 신기능

1.7 "Set Course!" 업데이트의 간판 기능. 이제 포켓몬을 타고 육지·물·하늘을 이동할 수 있어.

  1. 포켓몬을 필드에 꺼낸다.
  2. 웅크리기(Shift) + 우클릭 → 메뉴에서 타기 선택. (메뉴에 타기가 없으면 그 종은 탑승 불가)
  3. 육상은 W 더블탭으로 질주(1.7.1+), 비행·수영 타입은 각각 하늘·물속 이동. 비행엔 스태미나가 있어서 무한정은 못 날아.

자주 막히는 것들

아프리콘이 다시 안 자라요

부수면 재생 안 돼. 열매만 우클릭으로 수확하면 며칠 뒤 다시 열려.

포켓몬이 안 잡혀요

R키로 배틀 걸어 체력을 최대한 깎고, 마비·잠듦 상태이상을 걸면 포획 확률이 급상승해. HP를 1로 남기는 칼등치기 기술을 배운 포켓몬이 있으면 최고고, 상위 볼(슈퍼/하이퍼)도 도움 돼.

스타터를 다시 고르고 싶어요

불가능해(월드당 1회). 대신 모든 스타팅 포켓몬은 야생에서 초희귀로 자연 스폰되니 나중에 잡을 수 있어.

포켓몬 회복은 어떻게 해요?

①침대에서 자기 ②시간 경과 자연 회복 ③치료 머신 ④상처약. 초반엔 침대가 제일 빨라.

레벨이 됐는데 진화를 안 해요

파티 화면에서 해당 포켓몬의 진화 버튼을 직접 눌러줘야 해(자동 아님). 변함없는돌을 지니고 있으면 진화가 아예 안 돼.

통신교환 진화는 어떻게 해요?

링크 케이블을 들고 포켓몬에게 우클릭하면 돼. 원작에서 지닌 물건이 필요한 경우 그 아이템을 먼저 지니게 한 뒤 사용해. (진화 탭 참고)

잡은 포켓몬이 사라졌어요

파티가 6마리 꽉 차 있으면 새로 잡은 포켓몬은 자동으로 PC로 가. PC를 확인해봐.

배틀은 어떻게 걸어요?

파티에서 포켓몬을 선택한 뒤 R키(기본 키)를 눌러. 야생 포켓몬이나 다른 플레이어를 조준하고 누르면 돼.

포켓몬을 어깨에 태우거나 타고 싶어요

필드에 꺼낸 상태에서 웅크리기+우클릭. 소형 포켓몬은 어깨에 타고(일부는 수중호흡·신속 버프), 큰 포켓몬은 메뉴에 타기가 떠서 라이딩할 수 있어(1.7+). 위 라이딩 카드 참고.

이로치(색 다른 포켓몬) 확률은?

기본 1/4096이야. 화석 부활로도 이로치가 나올 수 있어.

알은 어떻게 얻어요?

목장 블록(Pasture Block)에 호환되는 포켓몬 2마리(또는 메타몽+아무나)를 넣으면 돼. 단, 가라르 화석 4종은 교배가 안 돼.

레시피를 못 찾겠어요

조합대 레시피북에서 영어 이름으로 검색해봐. 이 가이드 검색창에서 한→영 변환부터 하면 돼.

가장 중요한 팁: 게임을 한국어로!

코블몬은 공식 한국어 번역을 포함하고 있어. 마인크래프트 설정 → 언어 → 한국어로 바꾸면 코블몬 아이템·포켓몬 이름·UI 상당 부분이 한글로 표시돼 (번역률에 따라 일부는 영어로 남을 수 있음).

영어 위키에서 이름을 찾아야 할 땐 이 페이지 상단 검색창에서 한↔영 변환하면 돼.

레시피 확인 루틴

  1. 이 가이드 검색창에서 한국어 이름 → 영어 이름 확인
  2. 게임 내 조합대 레시피북에서 영어 이름 검색 (JEI/EMI 모드가 있으면 더 편함)
  3. 버전이 바뀌면 레시피가 바뀔 수 있으니 게임 내 표기가 항상 정답

둘이서 플레이 꿀팁

  • 진화 아이템 분업: 한 명은 얼음/바다 발굴지, 한 명은 사막/정글 담당하면 화석·아이템이 빨리 모여
  • 변함없는돌(Everstone)을 지니게 하면 진화 방지 — 귀여운 모습 유지용
  • 교배는 목장 블록(Pasture Block) — 메타몽이 있으면 대부분의 포켓몬과 교배 가능 (가라르 화석 4종 제외)
  • 이 HTML 파일은 오프라인에서도 열리니까 여자친구 폰에도 저장해줘

추천 편의 모드 (클라이언트 전용)

"전투 중에 상성이 자동으로 떴으면 좋겠다"는 딱 이 모드들로 해결돼. 클라이언트에만 설치하면 되고 Aternos 서버엔 안 넣어도 돼. Fabric 로더 + Fabric API 필요, 버전은 1.21.1 / Cobblemon 1.6+ 기준.

Cobblemon Effectiveness 다운로드 1위

전투 시작하면 상대 포켓몬에게 뭐가 2배·4배 효과적인지 깔끔한 오버레이로 표시. 다운로드 60만+(CurseForge 44.8만 + Modrinth 18.7만)로 이 분야 압도적 1위. 35KB로 초경량이라 그램 노트북(8GB)에도 부담 제로. 여자친구용 최우선 추천.

Cobblemon Type Effectiveness

기술 선택 타일에 0× / ½× / 1× / 2× / 4× 배율을 직접 겹쳐서 보여줌. 이중 타입 방어도 정확히 계산돼(예: 불꽃 → 물/비행 = ¼×). 기술 고를 때 바로 숫자가 보여서 직관적이지만, 다운로드 수는 위 모드보다 훨씬 적어(2,700+).

Extended Battle UI

상성 + 날씨 + 능력치 변화 + 데미지 %까지 다 보여주는 포켓쇼다운급. 기능이 많아서 익숙해지면 좋지만 초보한텐 살짝 복잡할 수 있어.

Modrinth·CurseForge에서 "Cobblemon Effectiveness"로 검색하면 나와. 여자친구용으로는 사용자가 가장 많은 Cobblemon Effectiveness 하나만 넣으면 충분해 — 전투 중 화면에 상성이 자동으로 떠서 검색할 필요가 없어져.

지금 무슨 지형인지 모르겠다면: BiomeInfo

탐험하다 보면 "이게 그냥 숲이야, 꽃 숲이야?" 헷갈릴 때가 많지. 마인크래프트 바이옴은 세분화돼 있어서(일반 숲 ≠ 꽃 숲 ≠ 자작나무 숲) 지형을 정확히 알아야 원하는 포켓몬을 제대로 찾을 수 있어.

방법 1 — BiomeInfo 모드 (강력 추천)

화면 구석에 현재 바이옴 이름을 자동으로 띄워주는 초경량 모드. 마크 전체에서 가장 유명한 바이옴 표시 모드로 다운로드 450만+. 새 지형에 들어가면 이름이 뜨고, 설정으로 항상 표시도 가능해. 클라이언트 전용, 위치·색상 커스텀 가능, 그램에도 부담 없어. Fabric판을 받으면 돼.

방법 2 — F3 디버그 화면 (모드 없이)

F3 키를 누르면 화면 왼쪽에 Biome: 항목이 뜨는데, 여기 minecraft:flower_forest처럼 정확한 바이옴 ID가 나와. 정보가 많아서 좀 복잡하지만 모드 없이 바로 확인할 수 있어. (노트북에선 Fn+F3일 수 있어.)

F3이나 BiomeInfo에서 본 영어 이름을 바이옴 스폰 탭 각 지형 카드에 병기된 마크 바이옴 ID와 맞춰보면 돼. 예: F3에 birch_forest가 뜨면 → "숲·자작나무 숲" 카드.
